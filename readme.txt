1. Beschreibung
###############

Einfaches Teamscript, welches Gruppen und seine Mitglieder
anzeigt. Gruppen und Mitglieder sind in einen Adminmenü
frei einstellbar.

2. Installation
###############

 1. Laden Sie den Inhalt vom "php_files" in das Hauptverzeichnis von PHP Fusion auf ihren Webspace

 2. Loggen Sie sich als mit entsprechenden Rechten ein und gehen Sie zum "System Admin" im Admin Panel.
    Dort klicken Sie auf "Infusionen" 

 3. Wählen Sie aus der Select Box "Gr Teamlist" aus und klicken auf "Installieren"

 4. Nun können Sie ihre Gruppen mit den Mitgliedern erstellen.

3. Hinweis
##########

Bilder für Gruppen und Mitglieder kann man in den Verzeichnissen "infusions/gr_teamlist/images/group/"
und "infusions/gr_teamlist/images/team/" hinzufügen.
