# Teamlist für PHP-Fusion

Fork von **Gr_Teamlist v2.2 für PHP-Fusion 7** von Ralf Thieme (Gr@n@dE), www.granade.eu.

Einfaches Teamscript, das Gruppen und ihre Mitglieder anzeigt. Gruppen und Mitglieder lassen sich in einem Adminmenü frei einstellen.

## Anforderungen

- PHP-Fusion 7
- PHP 5 bis 8.4
- MySQL ab 4.1 oder MariaDB

## Download

Die aktuelle Version gibt es unter [Releases](https://github.com/SchilinskiAlexander/gr_teamlist/releases) als ZIP-Datei `gr_teamlist_vX.X.zip`. Die Änderungen je Version stehen in [`CHANGELOG.md`](CHANGELOG.md).

## Installation

1. Den Inhalt von `php_files/` in das Hauptverzeichnis von PHP-Fusion hochladen.
2. Im Admin Panel unter „System Admin“ → „Infusionen“ den Eintrag „Gr Teamlist“ auswählen und installieren.
3. Gruppen und Mitglieder anlegen.

Bilder für Gruppen und Mitglieder kommen in `infusions/gr_teamlist/images/group/` und `infusions/gr_teamlist/images/team/`.
